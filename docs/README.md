## 阅读顺序

1. 只想「知道能不能做」→ 本页 + README §1/§4。
2. 要**评审方案**→ `gateway-design.md`（尤其 §3 与 §14 决策清单）。
3. 要**动手实现**→ `protocol-spec.md` → `eaglercraft-internals.md` §3–§6 → `references.md`。

## 文档约定

- 每条关键事实标注证据等级：
  - **[实测]**：我们自己在真机/无头浏览器/抓包上验证过（附脚本或日志位置）。
  - **[源码]**：上游开源代码可直接读到（附仓库 + 文件）。
  - **[推断]**：由协议/代码推导，尚未端到端验证——实现时必须补测。
- 日期一律写绝对日期（`2026-11-22`），不写「最近」。
